# KRX V2.1 데이터 정의 문의 초안

상태: `DRAFT_NOT_SENT`  
작성일: 2026-07-20  
용도: 비상업 학술연구의 사전등록 프로토콜 동결 전 공식 정의 확인

## 문의 제목

KRX Open API 과거 종목 구성·산업분류·기업행사 조정 및 연구 파생통계 공개 범위 문의

## 문의 본문

안녕하세요. 2025년 학부 팀 프로젝트의 후속 재현성 연구를 비상업 목적으로 진행하고 있습니다. 결과를 확인하기 전에 데이터 이용 시점과 수익률 생성 규칙을 고정하려고 하며, KRX Open API의 공식 정의에 관해 아래 사항을 문의드립니다.

사용 중인 서비스는 유가증권·코스닥 종목기본정보와 일별매매정보, KRX·KOSPI 시리즈 일별시세정보입니다. 인증키 값과 원시 응답은 공개하지 않습니다.

1. 종목기본정보 API의 요청 변수 `basDd`는 해당 날짜에 상장돼 있던 종목 구성을 의미합니까, 아니면 현재 종목을 대상으로 해당 기준일의 정보를 반환합니까?
2. 현재는 상장폐지된 종목도 과거 상장기간의 `basDd`를 요청하면 당시 구성종목으로 반환됩니까? 반환되지 않는다면 과거 시점별 상장종목 모집단을 복원할 공식 자료가 있습니까?
3. 종목기본정보의 `SECT_TP_NM` 필드의 정확한 정의와 가능한 값은 무엇입니까? 업종·산업분류가 아니라면 어떤 분류를 뜻합니까?
4. 과거 각 기준일에 유효했던 업종 또는 산업분류와 구성종목을 조회할 API·파일·유료 데이터 상품이 있습니까? 있다면 분류체계, 적용일, 변경이력도 함께 제공됩니까?
5. 합병, 회사분할, 종목명 변경 및 단축코드 변경 전후의 증권 또는 동일 기업을 연결하는 KRX의 영구 식별자나 공식 계보 자료가 있습니까? 표준코드/ISIN만으로 모든 사례를 추적할 수 있는지도 확인 부탁드립니다.
6. 일별매매정보의 `TDD_CLSPRC`와 `FLUC_RT`는 액면분할·주식병합·감자 등 기업행사를 어떤 방식으로 반영합니까? `FLUC_RT`가 전일 대비 수익률인지, 비교가격 조정률인지, 배당을 포함하는지도 공식 계산식과 함께 확인 부탁드립니다.
7. KRX 원시 응답을 공개하지 않고 연구자가 계산한 종목별 환율 베타, 월별 산업수익률, 예측치 및 산업 단위 집계 성능표만 공개 저장소에 게시하는 경우 허용 범위는 어디까지입니까? 출처표시 등 필요한 조건과 공개가 금지되는 파생 수준을 알려주시면 감사하겠습니다.

답변을 사전등록 문서의 데이터 정의 근거로 보존하려 합니다. 가능하면 관련 공식 명세·약관·상품 페이지도 함께 안내 부탁드립니다.

감사합니다.

## 내부 처리 규칙

- 발송 전 개인 연락처만 문의 채널에 입력하고 이 파일에는 추가하지 않는다.
- 답변 원문은 공개 저장소에 커밋하지 않는다. 공개 문서에는 답변일, 담당 부서, 공식 문서 URL과 허용된 요약만 기록한다.
- 답변이 모호하면 `UNRESOLVED`를 닫지 않는다.
- 문의 전후로 모델·타깃·성능 결과를 생성하지 않는다.
