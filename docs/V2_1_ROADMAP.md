# V2.1 실행 로드맵

## 목적

V2.1은 24개월 proof-of-concept의 숫자를 조금 개선하는 작업이 아니다. 표본 기간, 타깃, 기준모형과 평가 방법을 다시 고정해 다음 질문에 답하는 후속 연구다.

> 과거 정보만 사용해 만든 환율 민감도와 시차 산업 네트워크가 단순 기준모형보다 다음 달 산업 초과수익률을 안정적으로 예측하는가?

## V2에서 이어받을 것

- 환율 민감도, 외국인 수급, 산업 관계를 하나의 분석 흐름으로 연결한다.
- 산업 관계는 같은 달 동조가 아니라 `A_t → B_{t+1}` 시차 관계로 정의한다.
- 모든 변수와 관계는 해당 예측 시점까지 관측된 자료만으로 계산한다.
- 네트워크 변수가 도움이 되지 않는 결과도 그대로 보고한다.

## V2.1에서 바꿀 것

### 1. 데이터

- 최소 5년, 가능하면 10년의 일별 수정주가·환율·외국인 수급을 사용한다.
- 가격 조정 방식, 거래일 정렬, 결측치 처리와 환율 기준시점을 데이터 사전에 기록한다.
- 고정 50종목 표본과 시점별 구성종목 표본을 구분해 생존편향 민감도를 확인한다.
- 재배포 권한이 없는 원자료는 Git에 올리지 않고, 수집 방법·해시·파생 과정만 공개한다.

### 2. 타깃

- 주 타깃은 `다음 달 산업 수익률 - 같은 달 시장 수익률`인 산업 초과수익률로 정의한다.
- 방향 예측은 초과수익률의 부호를 별도 분류 문제로 다룬다.
- 작은 변화까지 상승·하락으로 강제하지 않도록 거래비용 또는 변동성 기반 중립 구간도 비교한다.

### 3. 변수와 네트워크

- 환율 민감도 β와 함께 표준오차, 설명력, rolling-window 안정성을 저장한다.
- 외국인 수급은 수준값과 시가총액 대비 표준화 값을 비교한다.
- 시차 네트워크는 rolling/expanding window 모두 실험한다.
- 최소 지지도뿐 아니라 최소 발생 횟수, permutation test와 FDR 보정을 적용한다.

### 4. 기준모형

모든 모형은 같은 Walk-forward 분할에서 비교한다.

1. Zero 또는 역사적 평균
2. 직전 달 수익률
3. Ridge/Elastic Net
4. 기본 Random Forest
5. 네트워크 Random Forest
6. 데이터가 충분할 때만 Gradient Boosting 계열

### 5. 평가

- 회귀: RMSE, MAE, out-of-sample R²
- 방향: Accuracy/Hit Rate, balanced accuracy, 95% 신뢰구간
- 증분효과: 동일 예측월의 기본모형과 네트워크 모형을 paired comparison으로 검정
- 안정성: 연도별, 환율 강세·약세, 고변동성·저변동성 구간별 결과
- 해석: permutation importance와 네트워크의 선행 산업 변화

Hit Rate는 보조지표로만 사용한다. 산업별 6개월처럼 작은 표본의 단순 비율을 성능 근거로 삼지 않는다.

## 공개 조건

V2.1 결과 버전은 다음 조건을 모두 만족할 때 태그한다.

- 원자료를 제외한 전 과정이 하나의 명령으로 다시 실행된다.
- 예측 시점 이후의 정보가 변수 생성에 들어가지 않는 테스트가 통과한다.
- 모든 모형이 동일한 예측월과 타깃으로 비교된다.
- 장기 표본과 구간별 결과, 불확실성 범위를 함께 공개한다.
- 네트워크 모형이 이기지 못해도 결과 파일과 해석을 그대로 남긴다.

## 현재 상태

V2.1의 연구 질문, 데이터 계약, 평가 기준과 공개 조건까지 준비되었다. 최신 장기 원자료의 출처와 재배포 조건을 확정한 뒤 데이터 수집·실험 단계로 진행한다. 따라서 현재 저장소의 V2 결과는 V2.1의 성능 주장으로 사용하지 않는다.
