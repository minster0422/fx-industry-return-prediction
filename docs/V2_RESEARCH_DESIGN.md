# V2 연구 설계

## 연구 질문

1. 환율 민감도 기반 종목군은 기간과 시장국면이 바뀌어도 안정적인가?
2. 같은 달 동조가 아니라 실제 한 달 시차 산업 관계가 존재하는가?
3. 시차 산업 네트워크 신호는 단순 기준모형보다 다음 달 수익률 예측을 개선하는가?

## 단계 1: 데이터 계보 확정

- 최소 5년, 가능하면 10년의 일별 데이터 확보
- 가격수정 방식, 휴장일 정렬, 환율 기준시점 명시
- 외국인 수급 변수의 단위와 변환식을 데이터 사전에 기록
- 50종목 고정표본의 생존편향을 별도 한계로 표시
- 원본, 정제, 월별 패널을 별도 디렉터리와 해시로 관리

## 단계 2: 군집화 개선

- 종목별 환율 β에 표준오차와 설명력 기록
- 평균 수익률 대신 변동성·하방위험·외국인 순매수 강도도 후보로 비교
- StandardScaler와 RobustScaler 비교
- Silhouette, Calinski–Harabasz, Davies–Bouldin을 함께 사용
- Rolling window에서 군집 이동률과 안정성 측정
- 군집 번호 대신 특성 기반 이름을 사후 부여

## 단계 3: 산업 관계를 시차 규칙으로 정의

같은 달 `A_t → B_t`가 아니라 다음을 계산한다.

```text
A가 t월 상승  →  B가 t+1월 상승
```

- Support·Confidence·Lift를 과거 창에서만 계산
- 최소 지지도와 최소 발생횟수를 함께 요구
- 월별 표본이 적으므로 permutation test 또는 bootstrap 적용
- 많은 산업쌍을 비교할 때 FDR 보정
- 관계의 방향성과 지속기간을 Rolling window로 확인

## 단계 4: 동적 네트워크 신호

V2 코드의 `network_signal`은 예측월 직전까지 확인된 선행 산업만 사용한다.

```text
network_signal(B, t)
  = Lift가 기준 이상인 선행 산업 A들의 t월 수익률 가중평균
```

관계가 없으면 0으로 두고 `leader_count`를 별도 변수로 남긴다. 상수인 산업별 평균상관을 붙이는 대신 매월 값이 바뀌며 계산시점이 명확한 변수를 만든다.

## 단계 5: 예측 비교

모든 모델을 같은 expanding-window에서 비교한다.

1. Zero return
2. 직전 달 수익률
3. Ridge/Elastic Net
4. 기본 Random Forest
5. 네트워크 신호를 추가한 Random Forest
6. 충분한 데이터가 있을 때만 Gradient Boosting 계열

평가지표는 RMSE, MAE, 방향 적중률을 기본으로 하고 산업별 결과와 전체 가중평균을 함께 보고한다. 네트워크 변수의 증분효과는 `기본 모델 vs 네트워크 모델`의 동일 예측월 paired comparison으로 검정한다.

## 단계 6: 결과 해석

- 산업별 feature importance와 permutation importance
- 환율 강세·약세 국면별 성능
- 네트워크 신호가 켜진 달과 꺼진 달의 오차 비교
- 바이오처럼 비정형 이벤트가 큰 산업은 별도 이벤트 변수 또는 예측 제외 기준 검토
- 경제적 의미는 거래비용을 포함한 간단한 백테스트 뒤에만 주장

## 성공 기준

V2의 성공은 복잡한 모델의 RMSE가 한 번 낮게 나오는 것이 아니다.

- 동일 코드로 결과가 다시 생성된다.
- 모든 feature의 관측 가능 시점이 설명된다.
- 기준모형과 공정하게 비교된다.
- 동조 신호의 효과가 여러 기간에서 반복된다.
- 효과가 없을 때도 그 결과를 그대로 보고한다.

## 현재 24개월 proof-of-concept

V2 코드를 기존 24개월 자료에 적용했을 때 네트워크 RF는 기본 RF보다 전체 RMSE가 약 0.3% 낮았지만, 단순 0 예측보다 RMSE가 높았다. 표본 수가 작고 월수익률의 평균이 0에 가까워 현재 결과만으로 네트워크 변수의 가치를 주장할 수 없다. 다음 단계는 모델을 더 복잡하게 만드는 것이 아니라 기간을 늘리고 paired out-of-sample 비교와 불확실성 구간을 추가하는 것이다.
