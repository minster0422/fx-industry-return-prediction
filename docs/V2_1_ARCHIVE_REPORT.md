# V2.1 KRX 원자료 보존 보고서

## 결론

2026-07-28에 KRX Open API 원자료 보존 작업을 완료했다. 계획한 요청 12,908건과 로컬에서 다시 검증된 gzip 원본 12,908건이 일치하며 남은 요청은 0건이다. 이 작업은 `RAW_ARCHIVE_ONLY_NO_RESEARCH_DERIVATIONS` 경계 안에서 수행했으므로 수익률, target, 예측, 모델, 성능지표, 백테스트와 `results/v2_1/`은 생성하지 않았다.

공개 저장소에는 원자료나 요청별 manifest를 올리지 않는다. 공개 가능한 집계와 출처·무결성 정보는 [`../data/metadata/v2_1_archive_summary.json`](../data/metadata/v2_1_archive_summary.json)에 기록했다.

## 보존 범위

| 항목 | 고정 범위 |
|---|---|
| 기관 | Korea Exchange |
| 서비스 | KRX Data Marketplace OPEN API |
| 후보 기간 | 2010-01-04~2026-06-30 |
| 날짜 규칙 | 월요일~금요일 후보일 4,302일 |
| 일별 endpoint | KOSPI 종목, KOSDAQ 종목, KOSPI 지수 |
| 기본정보 endpoint | KOSPI·KOSDAQ, 2026-06-30 snapshot |
| 총 계획 요청 | 12,908건 |
| 주 연구 표본 | `U0_LEGACY_50` 유지 |
| 로컬 원자료 범위 | 시장·기준일별 API 응답 전체 |

KRX 일별 endpoint는 종목별 응답이 아니라 해당 시장의 일별 응답을 반환한다. 따라서 로컬 원자료에는 U0 50종목만이 아니라 응답 당시 반환된 시장 전체 행이 들어 있다. 종목 선택이나 수익률 계산은 이 보존 단계에서 수행하지 않았다.

공식 서비스 안내에 따르면 일별 서비스는 2010년 이후 데이터를 제공한다. 이용 약관상 한 인증키의 일일 요청 한도는 00:00~24:00 기준 10,000회이며 수신정보의 제3자 제공은 제한된다. 이 때문에 인증정보와 원자료는 Git에서 제외하고, 일일 실행 예산은 공식 한도보다 작은 8,750회로 고정했다.

- 공식 서비스 목록: <https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd>
- 공식 이용 약관: <https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp>
- 약관 시행일: 2025-12-26
- 현재 API 승인기간: 2026-07-20~2027-07-19

## 제한 probe

성과와 무관하게 고정한 다섯 날짜 `2010-01-04`, `2015-12-30`, `2020-12-30`, `2025-12-30`, `2026-06-30`에서 KOSPI 종목·KOSDAQ 종목·KOSPI 지수의 15개 요청을 먼저 점검했다. 15개 모두 요청 기준일과 같은 날짜의 행을 반환했고 KOSPI 주 지수 행을 식별할 수 있었다. 이 검사는 데이터 이용 가능성과 schema만 확인했으며 이후 수익률은 계산하지 않았다.

## 연구적으로 아직 완료되지 않은 것

원자료 보존 완료는 V2.1 실증 완료나 프로토콜 동결을 뜻하지 않는다. 다음 항목은 그대로 남아 있다.

1. 기업행사를 반영한 일수익률 정의와 검증
2. KRX·ECOS의 예측시점 기준 공개시각
3. ECOS 수정정책과 운영 수집
4. 기존 10산업과 KRX 산업지수의 공식 구성 매핑
5. 종목별 β·산업수익률·예측행의 공개 허용 범위

따라서 프로토콜 상태는 `DRAFT_NOT_FROZEN`으로 유지한다. 이후 연구는 공식 근거가 확보된 뒤 원자료를 변환하는 별도 단계에서만 재개하며, 결과가 좋다는 이유로 기간·표본·필드·모델·지표를 바꾸지 않는다.
