# 2025 분석 재구성 감사

## 감사 범위

이 문서는 과거 프로젝트를 비난하기 위한 것이 아니라, 어떤 결과가 어떤 입력과 코드에서 나왔는지 다시 추적하기 위한 기록이다. 원본 파일은 수정하지 않았고 공개 저장소에는 필요한 정의와 소형 파생표만 옮겼다.

## 확인된 입력

- 원시 패널: 24,300행 × 26열
- 종목: 50개
- 거래일: 486일
- 기간: 2023-05-03~2025-04-30
- 산업: 10개, 산업별 5개 종목
- 산업 이진행렬: 24개월 × 10개 산업

## 1. 군집 수 선택

2025 발표는 Elbow와 평균 Silhouette를 함께 보고 `k=4`를 선택했다고 설명한다. 동일 세 변수와 표준화를 사용한 현재 Python 포트에서는 다음 결과가 나왔다.

- `k=2` Silhouette: 약 0.741
- `k=4` Silhouette: 약 0.348

이는 네 군집이 무조건 틀렸다는 뜻은 아니다. R과 Python의 K-means 초기화 차이, 군집 해석 목적, 외국인 변화의 극단값 영향을 함께 검토해야 한다. 다만 “Silhouette가 k=4를 지지했다”는 설명은 현재 재현 결과로 확인되지 않는다.

## 2. 산업 이진행렬과 보고된 연관규칙

제공된 24개월 이진행렬에서 모든 순서쌍을 직접 계산하면 보고된 CSV와 값이 일치하지 않는다.

예를 들어 미디어→반도체는 다음과 같다.

| 지표 | 보고값 | 제공 행렬 재계산 |
|---|---:|---:|
| Support | 0.217 | 0.292 |
| Confidence | 0.750 | 0.778 |
| Lift | 1.677 | 1.556 |

10개 보고 규칙 모두 적어도 하나의 지표가 다르다. 따라서 보고 규칙이 다른 버전의 이진행렬에서 생성됐거나, 수동 정리 중 서로 다른 실행 결과가 섞였을 가능성이 있다.

## 3. `mean_corr`의 실제 계산

합본 R 코드는 월별 상승 여부를 다음처럼 만든다.

```r
group_by(yearmon, 종목) %>%
summarise(up = any(ret > 0))
```

즉 월수익률이 양수인지가 아니라 **그 달에 하루라도 양의 일간수익률이 있었는지**를 본다. 재계산 결과 각 종목은 24개월 중 23~24개월이 상승으로 표시된다.

- 비대각 Lift 최댓값: 1.0
- Lift 1.4 이상 종목쌍: 0개
- `mean_corr`가 0이 아닌 종목: 0개

따라서 해당 실행 경로에서는 `mean_corr`가 Random Forest의 예측력을 높일 수 없다.

## 4. 동조변수의 시간 누수 가능성

설령 Lift 1.4 이상 쌍이 있었다고 해도, 기존 코드는 전체 24개월을 사용해 상관계수와 관계망을 한 번 계산한 뒤 과거 Walk-forward 행에 붙인다. 초기 예측시점에서 미래 월의 정보를 포함하게 된다.

V2에서는 각 feature month까지 관측된 자료만 사용해 시차 관계망을 다시 계산한다.

## 5. 예측 대상 월 정렬

기존 코드는 다음과 같이 `next_ret`을 만든다.

```r
mutate(next_ret = lead(mean_ret))
```

하지만 결과표와 그래프의 x축에는 현재 행의 `yearmon`을 저장한다. 그러므로 `yearmon=2024-05` 행의 `actual`은 실제로 2024-06 수익률이다.

- 코드에 표시된 feature month: 2024-05~2025-03
- 실제 target month: 2024-06~2025-04

V1 Python 포트는 두 열을 모두 저장해 혼동을 막는다.

## 6. 예측 성능 숫자

R `randomForest`와 Python `RandomForestRegressor`는 표본추출·노드크기·난수 소비 방식이 달라 숫자가 완전히 같지 않다. 구조적 포트에서는 여러 산업의 RMSE가 PPT 값과 가까웠지만 일부 Hit Rate는 달랐다. 따라서 현재 저장소는 PPT 표를 `reported` 기준자료로 보존하되, Python 결과를 동일 결과라고 부르지 않는다.

## 결론

재현 실패도 연구 결과다. 2025 프로젝트의 핵심 가치는 `mean_corr`라는 특정 수치가 아니라, 환율 반응과 산업 관계를 다음 달 예측에 연결하려 했던 문제 설정이다. V2는 그 문제 설정을 유지하면서 변수와 시간축을 다시 정의한다.
