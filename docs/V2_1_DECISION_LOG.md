# V2.1 연구 결정 로그

## 상태

- 프로토콜: `0.1.0-draft`
- 작성일: 2026-07-17
- 결과 생성 여부: 없음
- 동결 여부: 아니오
- 동결 차단 항목: `UNRESOLVED-01`~`04`

이 문서는 결과를 보기 전에 내린 결정과 변경 이력을 보존한다. V2.1 예측값이나 성능표가 한 번이라도 생성된 뒤에는 기존 결정을 삭제하지 않고 `DEVIATION`을 추가한다.

## UNRESOLVED 항목

### UNRESOLVED-01 — 가격수익률과 기업행사

- 문제: KRX 공식 안내는 일별매매정보 제공 범위는 명시하지만 수익률·가격 필드의 분할·합병·감자 조정 방식을 공개 안내만으로 확정할 수 없다.
- 추천안: KRX 일별 등락률 후보 필드를 사용하고 공식 기업행사 10건 이상으로 검증한다.
- 대안: 금융위원회 주식시세 API와 공식 권리일정 자료로 조정계수를 구성한다.
- 종료 증거: 필드 명세, 기업행사 목록, 전후 가격·수익률 검증표, 실패 0건.
- 결과 열람 전 결정: 필수.
- 2026-07-17 증거 추가: 금융위원회 공식 schema에서 `clpr`·`fltRt`를 확인했지만 기업행사 조정 정의는 없었다. 인증키가 없어 공식 사건과 KRX 가격을 대조하지 못했으므로 상태는 `BLOCKED`이다.
- 2026-07-17 2차 증거: KRX Open API 서비스 목록에서 분할·병합·감자 사건 모집단 API를 확인하지 못했다. KRX 데이터 분배상품의 종목이벤트는 별도 정보상품이므로 공식 사건 endpoint·파일과 이용조건도 동결 차단 증거에 추가한다.
- 2026-07-20 증거 추가: `TDD_CLSPRC`와 `FLUC_RT`를 포함한 고정 305행의 schema·숫자 변환은 검증했으나, 기업행사 조정 정의는 여전히 확인되지 않았다. `FLUC_RT`를 연구 수익률로 확정하지 않고 상태를 `BLOCKED`로 유지한다.

### UNRESOLVED-02 — KRX 공개 시각

- 문제: 월말 feature가 `forecast_as_of` 이전에 실제 이용 가능했는지 공개 안내만으로 확정되지 않는다.
- 추천안: KRX API 응답을 월말 거래일에 시간대별로 시험하고 최초 제공시각을 로그에 저장한다.
- 대안: 공식 답변·명세에서 배치 공개시각을 확인한다.
- 종료 증거: 공식 명세 또는 3거래일 이상 timestamp 로그.
- 결과 열람 전 결정: 필수.
- 2026-07-17 증거 추가: 약관의 24시간 이용 원칙은 데이터 최초 공개시각 근거가 아니며 서비스 명세에도 시각이 없다. 인증 후 3거래일 관측이 필요하므로 상태는 `BLOCKED`이다.
- 2026-07-17 2차 증거: 공식 종가 분배상품은 16:00·18:10 전송을 명시하지만 Open API의 최초 게시시각과 동일하다고 추정하지 않는다. `timestamp_once` 관측은 키 부재로 0거래일이다.

### UNRESOLVED-03 — ECOS 환율 항목

- 문제: USD/KRW 일별 통계표·항목코드, 고시/종가/평균 구분, 원화/외화 방향과 공개 시각이 미확정이다.
- 추천안: ECOS 메타데이터 API로 후보를 검색하고 원화/달러 일별 종가 또는 공식 기준환율 한 계열을 고정한다.
- 대안: 동일 정의를 가진 다른 공식 공공데이터 계열.
- 종료 증거: 통계표 코드, 항목코드, 단위, 최초·최종일, 5개 날짜 수동 대조, 공개시각.
- 결과 열람 전 결정: 필수.
- 2026-07-17 증거 추가: 통계표 `731Y001`, USD `0000001`, EUR `0000003`, JPY `0000002`, CNY `0000053`의 명칭·단위·방향·기간과 5개 날짜를 확인했다. 이 하위 결정은 종료했으나 공개시각과 수정정책은 확인되지 않아 전체 상태는 `OPEN`이다.

### UNRESOLVED-04 — KRX 산업지수 매핑

- 문제: 기존 10개 사용자 정의 산업과 KRX 공식 산업지수가 일대일로 대응하지 않을 수 있다.
- 추천안: 결과를 보지 않고 명칭·구성 정의만으로 사전 매핑하고 정확·부분·불가를 라벨링한다.
- 제외 규칙: 정확 또는 부분 매핑이 8개 산업 미만이면 산업지수 민감도 분석 전체를 제외한다.
- 종료 증거: 10행 매핑표, KRX 지수코드, 매핑 등급과 근거.
- 결과 열람 전 결정: 필수.
- 2026-07-17 증거 추가: 6개 후보 지수명은 확인했지만 코드와 공식 구성 정의가 없다. 10행 모두 `unavailable`, `exact + partial = 0`이므로 민감도 분석은 현재 제외하고 상태는 `BLOCKED`이다.

### UNRESOLVED-05 — 외국인 수급

- 문제: KRX Data Marketplace에는 투자자별 거래와 외국인 보유 자료가 보이지만 동일 정의의 장기 공식 API·공개시점·제3자 제공 조건이 확정되지 않았다.
- 추천안: 주 분석에서 제외하고 공식 장기 자료가 다섯 조건을 만족할 때만 민감도 분석으로 추가한다.
- 대안: 제외 상태 유지.
- 종료 증거: 공식 명세, 기간, 커버리지, 공개시점, 이용조건.
- 동결 차단 여부: 아니오. 미해결이면 민감도 분석을 제외한다.

### UNRESOLVED-06 — 파생 결과 공개 범위

- 문제: 원자료를 제외하더라도 종목별 β, 산업별 실제수익률, 예측행을 공개 저장소에서 제3자에게 제공할 수 있는지 공식 안내만으로 확정되지 않는다.
- 추천안: KRX·ECOS에 공개 가능한 파생 수준을 서면 문의하고 답변을 보존한다.
- 대안: 행 단위 파생 파일은 로컬 생성으로 제한하고 코드, schema, 해시, 허용된 집계 지표만 공개한다.
- 종료 증거: 공식 약관 조항 또는 기관 답변, 허용/금지 파일 목록.
- 동결 차단 여부: 연구 프로토콜은 아니오, 공개 릴리스는 예.
- 2026-07-17 증거 추가: KRX 약관의 수신정보 제3자 제공 제한은 확인했지만 종목별 β·산업별 실제수익률·예측행의 공개 허용 여부는 추정하지 않는다. 상태는 `OPEN`이다.
