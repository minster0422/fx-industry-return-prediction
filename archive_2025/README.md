# 2025 project archive policy

이 디렉터리는 2025년 자료를 무분별하게 복사하는 장소가 아니다. 당시 산출물의 역할과 공개 위치를 기록하고, 개인정보·저작권·재배포 조건이 확인된 파일만 보존한다.

## 확인한 핵심 산출물

- DBpia 게재 논문: 공식 공개 주장
- 학회 최종 PPT 27장: 발표 표·그래프
- 발표 대본 9쪽: 발표 논리와 애니메이션 지시
- 합본 R 코드 493줄: 군집화·연관분석·예측 실행 흔적
- 24,300행 원시 패널과 소형 파생 CSV

## 공개하지 않는 로컬 자료

- 항공·결제 영수증
- 통장 사본
- 개인정보 동의서와 지원 신청서
- 교수자 강의자료와 시험자료
- 이름만 다른 다수의 중간 Word·PPT 파일
- 출처와 재배포 조건이 확정되지 않은 원시 시장 데이터
